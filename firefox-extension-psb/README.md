# Firefox extension — Ozon Bill / ПСБ

Отдельное расширение для автоматического импорта CSV-выписки ПСБ. Расширение Ozon не изменяет.

## Установка

1. Запустите локальное приложение Ozon Bill командой `./run.sh`.
2. В Firefox откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение…» и выберите `manifest.json` из этой папки.
4. Откройте личный кабинет ПСБ, перейдите на страницу нужной выписки и задайте период.
5. Нажмите значок «Ozon Bill — импорт ПСБ».
6. Расширение нажмёт штатный пункт «Получить выписку → Скачать в CSV», перехватит содержимое CSV и отправит его на `127.0.0.1:8765/api/psb/auto-sync`.
7. Уведомление покажет количество новых, обновлённых и уже имеющихся операций.

## Безопасность

- Используется только уже открытая и авторизованная вкладка ПСБ.
- Расширение не запрашивает и не сохраняет логин, пароль, cookies или токены.
- Содержимое выписки отправляется только локальному приложению на loopback-адрес.
- Экспорт инициируется только после нажатия пользователем значка расширения.
- Данные записываются в отдельную таблицу `psb_operations`; история Ozon не затрагивается.

## Ограничение текущей версии

Текущая реализация перехватывает CSV, если страница ПСБ формирует его как Blob или получает текст CSV через Fetch. Если банк начнёт скачивать файл прямым браузерным запросом, не отдавая содержимое странице, способ перехвата потребуется адаптировать. Проверка на реальном аккаунте ПСБ обязательна: скриншот подтверждает подписи и расположение элементов, но не внутренний механизм формирования файла.

Для повторной загрузки временного дополнения после перезапуска Firefox используйте `about:debugging`.
