# Firefox extension — Ozon Bill / ПСБ

Отдельное расширение для тихого импорта выписки ПСБ. Расширение Ozon не изменяет.

## Работа без предварительного открытия банка

1. Запустите локальное приложение Ozon Bill: `./run.sh`.
2. Убедитесь, что в этом же профиле Firefox ранее выполнен вход в ПСБ и сессия ещё действительна.
3. Нажмите значок расширения — открывать сайт ПСБ вручную не нужно.
4. Расширение создаст вкладку с заданной страницей выписки с параметром `active: false`. Она не выведет Firefox на передний план.
5. В фоновой вкладке расширение нажмёт «Получить выписку» → «Скачать в CSV», перехватит CSV и отправит его на локальный API.
6. Вкладка закроется, а уведомление покажет результат.

## Установка

1. Откройте в Firefox `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение…».
3. Выберите `manifest.json` из этой папки.
4. Закрепите значок расширения на панели Firefox для удобного запуска.

## Авторизация и ограничения

Firefox использует текущую сессию профиля. Расширение не получает и не хранит пароль, PIN, cookies или токены. Если сессия истекла, требуется подтверждение или дополнительная проверка, автоматический импорт остановится с уведомлением — войдите в ПСБ вручную и повторите.

Перехват CSV поддерживает Blob, Fetch и XHR. Если сайт использует прямой download-механизм, который не передаёт CSV через эти интерфейсы страницы, потребуется адаптация по фактическому сетевому запросу. Реальный импорт нужно проверить на авторизованном аккаунте.

CSV отправляется только на локальный адрес `127.0.0.1:8765`, а операции сохраняются отдельно в `psb_operations`.
