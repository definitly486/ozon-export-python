Автоматическое скачивание выписки ПСБ
  1. Откройте в обычном Firefox страницу выписки нужной карты ПСБ и войдите в личный кабинет.
  2. Выберите период выписки.
  3. Создайте закладку Firefox с кодом ниже. На странице ПСБ нажмите эту закладку: она откроет меню выписки (если оно закрыто) и выберет «Скачать в CSV».
  4. Выберите скачанный CSV в блоке выше и нажмите «Импортировать выписку ПСБ».

Закладка не читает и не сохраняет пароль, токен или cookies. Скачивание выполняет сам интернет-банк в вашей авторизованной вкладке. Период предварительно задайте на странице ПСБ.

Ежедневное обновление
  1. Откройте Ozon Банк в обычном Firefox и войдите в аккаунт.
  2. Создайте закладку Firefox с адресом из поля ниже (скопируйте весь код в поле «Адрес»).
  3. На вкладке Ozon нажмите эту закладку. Браузер скачает JSON со всей доступной историей.
  4. Выберите скачанный JSON выше и нажмите «Обновить базу и показать». Новые операции добавятся, изменившиеся обновятся, повторы не создадутся.

SQLite хранит локальную историю между запусками. Повторная полная выгрузка безопасна: записи сопоставляются по lastOperationId, а HOLD обновится, если позднее станет CONFIRMED. Саму выгрузку по-прежнему нужно запускать вручную в авторизованном Firefox.
