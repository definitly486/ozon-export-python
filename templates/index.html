OZON БАНК

Выписка по операциям

Локальный Python-инструмент для выгрузки операций в CSV

FreeBSD / Python
Используется обычный Firefox, без Selenium
Как получить файл из Ozon
  1. Откройте Ozon Банк в обычном Firefox и войдите в аккаунт.
  2. Создайте закладку Firefox с адресом из поля ниже (скопируйте весь код в поле «Адрес»).
  3. На вкладке Ozon нажмите эту закладку. Браузер скачает JSON с операциями.
  4. Выберите скачанный JSON выше и нажмите «Импортировать операции».

Экспорт запускается вручную в обычной вкладке Ozon. Selenium, GeckoDriver и отдельный автоматизированный профиль больше не используются.
