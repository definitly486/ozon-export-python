# Ozon Bill — Python / FreeBSD (обычный Firefox)

Локальное приложение для импорта операций Ozon Банка и экспорта выбранных строк в CSV. Работает с обычным Firefox пользователя — без Selenium, GeckoDriver, автоматизированного профиля и отдельного браузерного процесса.

## Почему изменён способ подключения

Предыдущая версия открывала Firefox через Selenium. Некоторые сайты могут распознавать управляемый WebDriver браузер и показывать проверку безопасности или ошибочное предупреждение о VPN. Эта версия не управляет браузером: пользователь открывает Ozon в привычном Firefox и запускает закладку-экспорт непосредственно на странице банка. Закладка делает запрос из авторизованного контекста страницы и сохраняет JSON-файл. Затем файл импортируется в локальное приложение.

## Установка на FreeBSD

Нужен Python 3. Устанавливать Firefox и GeckoDriver для приложения не требуется — используется уже установленный обычный Firefox.

```sh
sudo pkg install python
```

Распакуйте проект и запустите:

```sh
chmod +x run.sh
./run.sh
```

Откройте `http://127.0.0.1:8765` в Firefox.

## Использование

1. Нажмите **Открыть Ozon Банк в Firefox** или откройте `https://finance.ozon.ru/lk` вручную.
2. Войдите в личный кабинет обычным способом.
3. В локальном приложении нажмите **Скопировать код закладки**.
4. Создайте в Firefox новую закладку. В поле «Имя» можно указать `Выгрузить операции Ozon`, а в поле «Адрес» вставьте скопированный код, начинающийся с `javascript:`.
5. Переключитесь на вкладку Ozon Банка и нажмите созданную закладку. После завершения загрузится файл `ozon_operations_raw.json`.
6. В локальном приложении выберите этот JSON-файл, задайте даты и нажмите **Обновить базу и показать**.
7. Выберите нужные строки и скачайте CSV.

Если Firefox не разрешает вставить код в адрес закладки, создайте закладку через менеджер закладок (`Ctrl+Shift+O`) и вставьте код именно в поле «Адрес/Location», а не в адресную строку.

## Безопасность и ограничения

- Приложение не получает и не хранит логин, пароль или cookies. Сессия остаётся в обычном профиле Firefox.
- JSON содержит личные банковские операции. Храните его локально и удаляйте после импорта, если он больше не нужен.
- Используется внутренний endpoint веб-кабинета `groupOperationsV3`, а не официальный публичный API Ozon Банка. Ozon может изменить его контракт или ограничить доступ.
- Экспорт закладки запускается пользователем вручную на сайте банка. Никаких попыток обходить защиту сайта или маскировать автоматизацию нет.
- После импорта сравните суммы и несколько операций с выпиской в личном кабинете. Формат суммы/знака может измениться на стороне Ozon.

## Правила импорта и CSV

- В CSV попадают только операции со статусом `GROUP_OPERATION_CONFIRMED`.
- `GROUP_OPERATION_HOLD` (временные блокировки) и любые другие неподтверждённые статусы не экспортируются как списания. Они остаются в исходном JSON.
- Тип `AUTHORIZATION` сам по себе не является причиной исключения: запись включается только если её статус подтверждён. Это важно, чтобы не потерять подтверждённые карточные операции.
- Сумма и направление движения берутся из `accountAmount`, а не из `originalAmount`. Неизвестный знак или валюта приводят к ошибке импорта вместо неверного расчёта.
- Даты периода сопоставляются с локальной датой компьютера — той же датой, которая отображается в таблице.


## Ежедневное обновление и локальная база

Приложение сохраняет полученную историю в SQLite-файл `data/ozon_operations.sqlite3`. База создаётся автоматически при первом запуске; данные остаются на компьютере между перезапусками приложения.

Ежедневный порядок действий:

1. Запустите приложение командой `./run.sh` и откройте `http://127.0.0.1:8765`.
2. В обычном Firefox откройте Ozon Банк и войдите в аккаунт.
3. Нажмите закладку-экспорт на странице банка и дождитесь скачивания `ozon_operations_raw.json`.
4. Выберите этот файл в приложении и нажмите **Обновить базу и показать**.
5. Приложение объединит выгрузку с локальной историей и покажет операции за выбранный период. CSV можно скачать как раньше.

### Как работает объединение

- Ключ записи — `lastOperationId`. Повторная выгрузка не создаёт дубликаты.
- Новые операции добавляются, а изменившиеся записи обновляются.
- Если операция изменила статус с `GROUP_OPERATION_HOLD` на `GROUP_OPERATION_CONFIRMED`, в базе сохраняется новый статус; после этого операция может попасть в CSV.
- Неизменившиеся записи остаются без перезаписи. В интерфейсе отображается число новых, изменённых, неизменившихся и пропущенных записей.
- В базе хранятся исходные поля операций, включая HOLD и другие статусы. В денежный CSV по-прежнему попадают только подтверждённые операции.
- При каждой синхронизации закладка повторно загружает доступную историю из Ozon; SQLite выполняет локальное объединение. Это намеренно не ограничивает загрузку только последними семью днями: так не теряются операции, которые могли подтвердиться или измениться с задержкой.

### Где хранится база

По умолчанию: `data/ozon_operations.sqlite3` внутри каталога проекта. Чтобы выбрать другой путь, задайте переменную окружения `OZON_DB_PATH` перед запуском, например:

```sh
OZON_DB_PATH="$HOME/.local/share/ozon-export/operations.sqlite3" ./run.sh
```

Файл SQLite содержит историю личных банковских операций. Не добавляйте его в Git и не публикуйте. В репозитории каталог `data/` исключён через `.gitignore`.

**Автоматический фоновый сбор не включён.** Вход в Ozon и запуск закладки остаются ручными действиями в авторизованном Firefox. Приложение автоматизирует сохранение, объединение, дедупликацию и подготовку CSV после загрузки файла.

## Технические требования

- Python 3
- Flask
- Обычный Firefox — для входа и запуска закладки

Переменные `FIREFOX_BINARY`, `GECKODRIVER` и `OZON_FIREFOX_PROFILE` больше не используются.


## Импорт выписок ПСБ

Помимо Ozon Банк приложение принимает CSV-выписки ПСБ для физических лиц:

1. В приложении ПСБ сформируйте выписку за нужный период и сохраните её в CSV.
2. В веб-интерфейсе Ozon Bill укажите период отображения, выберите файл в блоке **CSV-выписка ПСБ** и нажмите **Импортировать выписку ПСБ**.
3. Операции ПСБ появятся в общей таблице вместе с операциями Ozon. Выгрузка выбранных строк остаётся общей.

Импортёр читает CSV с разделителем `;`, десятичной запятой и UTF-8 BOM. Для суммы используется поле **«Сумма в валюте карты»** со знаком: отрицательное значение — расход, положительное — поступление. Валюта, отличная от RUR/RUB, отклоняется, чтобы не смешивать разные валюты в общем денежном CSV.

ПСБ не предоставляет в этой выписке отдельный ID операции, поэтому приложение формирует стабильный SHA-256 ключ из даты/времени операции, даты обработки, описания, суммы и валюты. Повторная загрузка пересекающихся периодов не создаёт повторные строки. Записи ПСБ хранятся отдельно в таблице `psb_operations` того же локального SQLite-файла; таблица и алгоритм импорта Ozon не изменяются.

Перед использованием сверяйте итоговые суммы приложения с выпиской банка. Файл выписки содержит финансовые данные — храните его локально.
