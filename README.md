# Ozon Bill — Python / FreeBSD (обычный Firefox)

Локальное приложение для импорта операций Ozon Банка и экспорта выбранных строк в CSV. Работает с обычным Firefox пользователя — без Selenium, GeckoDriver, автоматизированного профиля и отдельного браузерного процесса.

## Почему изменён способ подключения

Предыдущая версия открывала Firefox через Selenium. Некоторые сайты могут распознавать управляемый WebDriver браузер и показывать проверку безопасности или ошибочное предупреждение о VPN. Эта версия не управляет браузером: пользователь открывает Ozon в привычном Firefox и запускает закладку-экспорт непосредственно на странице банка. Закладка делает запрос из авторизованного контекста страницы и сохраняет JSON-файл. Затем файл импортируется в локальное приложение.

## Установка на FreeBSD

Нужен Python 3. Устанавливать Firefox и GeckoDriver для приложения не требуется — используется уже установленный обычный Firefox.

```sh
sudo pkg install python
```

Распакуйте проект и запустите:

```sh
chmod +x run.sh
./run.sh
```

Откройте `http://127.0.0.1:8765` в Firefox.

## Использование

1. Нажмите **Открыть Ozon Банк в Firefox** или откройте `https://finance.ozon.ru/lk` вручную.
2. Войдите в личный кабинет обычным способом.
3. В локальном приложении нажмите **Скопировать код закладки**.
4. Создайте в Firefox новую закладку. В поле «Имя» можно указать `Выгрузить операции Ozon`, а в поле «Адрес» вставьте скопированный код, начинающийся с `javascript:`.
5. Переключитесь на вкладку Ozon Банка и нажмите созданную закладку. После завершения загрузится файл `ozon_operations_raw.json`.
6. В локальном приложении выберите этот JSON-файл, задайте даты и нажмите **Обновить базу и показать**.
7. Выберите нужные строки и скачайте CSV.

Если Firefox не разрешает вставить код в адрес закладки, создайте закладку через менеджер закладок (`Ctrl+Shift+O`) и вставьте код именно в поле «Адрес/Location», а не в адресную строку.

## Безопасность и ограничения

- Приложение не получает и не хранит логин, пароль или cookies. Сессия остаётся в обычном профиле Firefox.
- JSON содержит личные банковские операции. Храните его локально и удаляйте после импорта, если он больше не нужен.
- Используется внутренний endpoint веб-кабинета `groupOperationsV3`, а не официальный публичный API Ozon Банка. Ozon может изменить его контракт или ограничить доступ.
- Экспорт закладки запускается пользователем вручную на сайте банка. Никаких попыток обходить защиту сайта или маскировать автоматизацию нет.
- После импорта сравните суммы и несколько операций с выпиской в личном кабинете. Формат суммы/знака может измениться на стороне Ozon.

## Правила импорта и CSV

- В CSV попадают только операции со статусом `GROUP_OPERATION_CONFIRMED`.
- `GROUP_OPERATION_HOLD` (временные блокировки) и любые другие неподтверждённые статусы не экспортируются как списания. Они остаются в исходном JSON.
- Тип `AUTHORIZATION` сам по себе не является причиной исключения: запись включается только если её статус подтверждён. Это важно, чтобы не потерять подтверждённые карточные операции.
- Сумма и направление движения берутся из `accountAmount`, а не из `originalAmount`. Неизвестный знак или валюта приводят к ошибке импорта вместо неверного расчёта.
- Для выписок ПСБ период фильтруется по дате обработки транзакции, как в банковской выписке; в таблице сохраняется фактическое время совершения операции. Поэтому операция, совершённая до начала периода, но обработанная внутри него, не теряется.


## Локальная база

Приложение сохраняет полученную историю в SQLite-файл `data/ozon_operations.sqlite3`. База создаётся автоматически при первом запуске; данные остаются на компьютере между перезапусками приложения.

### Как работает объединение

- Ключ записи Ozon — `lastOperationId`. Повторная выгрузка не создаёт дубликаты.
- Новые операции добавляются, а изменившиеся записи обновляются.
- Если операция изменила статус с `GROUP_OPERATION_HOLD` на `GROUP_OPERATION_CONFIRMED`, в базе сохраняется новый статус; после этого операция может попасть в CSV.
- В базе хранятся исходные поля операций, включая HOLD и другие статусы. В денежный CSV по-прежнему попадают только подтверждённые операции.
- Данные ПСБ хранятся отдельно в таблице `psb_operations`.

### Где хранится база

По умолчанию: `data/ozon_operations.sqlite3` внутри каталога проекта. Чтобы выбрать другой путь, задайте переменную окружения `OZON_DB_PATH` перед запуском, например:

```sh
OZON_DB_PATH="$HOME/.local/share/ozon-export/operations.sqlite3" ./run.sh
```

Файл SQLite содержит историю личных банковских операций. Не добавляйте его в Git и не публикуйте. В репозитории каталог `data/` исключён через `.gitignore`.

## Технические требования

- Python 3

## Автоматический импорт ПСБ через Firefox

Для ПСБ используется отдельное расширение из папки `firefox-extension-psb/`. Ручное создание закладки и выбор CSV-файла в интерфейсе больше не нужны.

1. Запустите Ozon Bill командой `./run.sh`.
2. Войдите в ПСБ в обычном Firefox. После входа можно оставаться на главной странице личного кабинета `/lk/products/summary`.
3. Откройте `about:debugging#/runtime/this-firefox`, нажмите **«Загрузить временное дополнение…»** и выберите `firefox-extension-psb/manifest.json`.
4. Нажмите значок расширения. Оно использует текущую авторизованную вкладку, переходит к выписке в этой же вкладке, получает CSV и отправляет его в локальное приложение.
5. Дождитесь уведомления о результате. Операции сохраняются в отдельной таблице `psb_operations` и отображаются в общей таблице с Ozon.

6. Если CSV-выписка ПСБ скачана в папку `Downloads` обычным способом, приложение автоматически обнаружит новый файл и импортирует его после завершения загрузки. Проверка выполняется примерно раз в 2 секунды; повторный импорт не создаёт дубликаты. Уже находившиеся в папке файлы при запуске приложения автоматически не импортируются.

**Важно:** расширение ПСБ не создаёт новую вкладку, поскольку банк может повторно запросить пароль при открытии новой страницы. Оно не хранит логин, пароль, PIN, cookies или токены. Если сессия завершилась, войдите в банк вручную и повторите импорт. Временное дополнение нужно загрузить снова после перезапуска Firefox.

Расширение перехватывает CSV через Blob, Fetch и XHR страницы. Если ПСБ изменит интерфейс или механизм скачивания, может потребоваться адаптация. Реальный импорт следует сверить с банковской выпиской после первого запуска.

Импортёр использует поле **«Сумма в валюте карты»** со знаком: отрицательное значение — расход, положительное — поступление. Валюта, отличная от RUR/RUB, отклоняется. ПСБ не предоставляет в этой выписке отдельный ID операции, поэтому приложение формирует стабильный SHA-256 ключ для дедупликации. Данные ПСБ хранятся отдельно; таблица и алгоритм импорта Ozon не изменяются.

## Автоматический импорт Ozon через Firefox

В экспериментальной ветке доступно расширение `firefox-extension/`. Запустите приложение, откройте `about:debugging#/runtime/this-firefox`, загрузите `firefox-extension/manifest.json` как временное дополнение, затем войдите в Ozon Банк и нажмите значок расширения. JSON будет передан напрямую в локальную SQLite-базу — выбирать файл вручную не нужно.

Это не официальный публичный API: расширение использует внутренний метод веб-приложения Ozon и может потребовать обновления, если Ozon изменит сайт. Оно не хранит учётные данные и работает только по явному нажатию.

## Отдельная вкладка «Чеки»

Откройте `http://127.0.0.1:8765/receipts` или нажмите **«Чеки»** в шапке приложения. Для импорта выберите JSON-выгрузку с верхнеуровневым массивом `receipts` (поля `exportedAt`, `listComplete`, `detailsComplete` сохраняются как метаданные последней выгрузки).

- Чеки хранятся в отдельной таблице SQLite `receipts`; существующая таблица банковских операций и её импорт не меняются.
- Дедупликация выполняется по `receipt.key`, а при его отсутствии — по фискальному накопителю, номеру документа и фискальному признаку.
- Повторный импорт обновляет изменившиеся данные и не создаёт копии.
- В списке доступны дата, продавец, ИНН, фискальный номер и сумма. Нажмите на строку, чтобы раскрыть товары, количество, цену, сумму, НДС, способ оплаты и фискальные реквизиты.
- Поиск работает по продавцу, ИНН, номеру документа и названиям товаров.
- Полнота списка и деталей показывается отдельно от количества импортированных чеков.

Импорт чеков сейчас выполняется отдельным JSON-файлом на странице «Чеки». Существующее расширение Firefox продолжает импортировать банковские операции; его механизм получения чеков не меняется без отдельного подтверждённого endpoint выгрузки чеков Ozon.
